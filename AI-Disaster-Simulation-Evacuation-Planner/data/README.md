# data/

| Folder | What goes here | In Git? |
|---|---|---|
| `sample/` | the **synthetic** demo dataset (`demo_scenario.json`), generated by `scripts/generate_sample_data.py` | yes |
| `raw/roads/`, `raw/population/`, `raw/shelters/` | files exactly as downloaded. Never edited. | no |
| `external/` | other third-party reference data you download | no |
| `processed/` | pipeline output: `<name>.json` + `<name>.manifest.json` | no |

Synthetic and real data never share a file. Every dataset records, per layer (roads / population / shelters),
whether it is `synthetic`, `real` or `derived`, and where it came from (`meta.provenance`).

## Expected raw files

**Roads** `data/raw/roads/roads.geojson`: GeoJSON `FeatureCollection` of `LineString` / `MultiLineString`, WGS84
lon/lat. A `highway` property (OpenStreetMap tag) marks arterial roads (motorway, trunk, primary, secondary + links).
Roads must share coordinates where they meet (an OSM export does). Source: OpenStreetMap (ODbL licence), e.g. an
Overpass Turbo export of `highway` ways for your area, or a Geofabrik extract converted to GeoJSON.

**Population** `data/raw/population/population.csv`: columns `lat, lon, population` (aliases: latitude, longitude, pop,
people, count). One row per point or grid-cell centre. Source: a gridded population dataset converted to points
(e.g. WorldPop or GHSL), or your own census centroids. Check each source's licence.

**Shelters** `data/raw/shelters/shelters.csv`: columns `lat, lon, capacity` and optionally `name, occupancy`.
Source: your local disaster-management authority's shelter list. There is no global public shelter dataset to download.

Files are read as UTF-8 (Excel's "CSV UTF-8" is fine), comma separated, one header row.

## Build, check, use
    python scripts/build_dataset.py --name my_city --roads-license "ODbL" --population-license "<licence>"
    python scripts/validate_dataset.py data/processed/my_city.json
    # then in .env:  PLANNER_DATASET=data/processed/my_city.json   and restart
